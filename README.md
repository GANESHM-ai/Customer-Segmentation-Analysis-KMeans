# Customer-Segmentation-Analysis-KMeans
supervised ML project segmenting mall customers based on income and spending habits using K-Means clustering to optimize marketing strategy.

##  Project Overview
This project focuses on **Customer Segmentation** using machine learning techniques to group customers based on their purchasing behavior.  
The goal is to help businesses understand customers better and design targeted marketing strategies.

##  Objectives
- Analyze customer data
- Perform data preprocessing & feature scaling
- Apply clustering algorithms
- Visualize customer segments
- Extract business insights

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- K-Means

##  Dataset Description
The dataset contains customer-related attributes such as:
- Customer ID
- Age
- Annual Income
- Spending Score
- Purchase Frequency

##  Steps Involved
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Scaling
5. Applying K-Means Clustering
6. Optimal Cluster Selection (Elbow Method)
7. Visualization of Clusters
8. Business Insights

##  Machine Learning Algorithm
- **K-Means Clustering**
- Used **Elbow Method** to find optimal number of clusters

##  Results
- Customers grouped into meaningful clusters
- Identified:
  - High-value customers
  - Budget-conscious customers
  - Occasional buyers

##  Visualizations
- Cluster scatter plots
- Elbow curve
- Spending behavior charts
